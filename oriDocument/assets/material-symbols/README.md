# 底部导航图标

这些 SVG 是原始 HTML 通过 `Material Symbols Outlined` 字体引用的同名图标，已按原型使用的默认参数（24px、outlined、weight 400、fill 0）保存为本地文件。

| 页面含义 | Material Symbols 名称 | 文件 |
| --- | --- | --- |
| 管理员排班 | `view_quilt` | `view_quilt.svg` |
| 助理填报 | `edit_note` | `edit_note.svg` |
| 日程 | `calendar_month` | `calendar_month.svg` |
| 团队 | `groups` | `groups.svg` |
| 个人 | `person` | `person.svg` |

来源：Google Material Symbols，Apache License 2.0。

- 仓库：https://github.com/google/material-design-icons
- 图标资源：https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsoutlined/{icon}/default/24px.svg

`miniprogram/assets/icons` 中是供小程序底部导航使用的普通态和选中态配色版本。
